KEY LEARNING

What should you observe?

Waiting behaviour

Synchronous execution includes waiting for each response before moving forward.

Independent progress

Asynchronous execution allows a process to continue while a message is in transit.

Trade-off

Asynchronous systems can improve responsiveness but need careful response tracking and error handling.
